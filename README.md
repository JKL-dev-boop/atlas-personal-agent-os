# ATLAS · 个人 Agent OS

ATLAS 是一个面向个人长期使用的模块化数字工作台。它把信息采集、项目追踪、演示资料、知识管理、自动任务和 Agent/Sandbox 实验放在同一套内容与运行模型中。

当前首批能力：

- GitHub 日报：AI / Agent、应用项目、K8s / 容器 / Sandbox 三个分区。
- 项目雷达：保存每日快照，追踪 Star、Release 和重复项目的新增变化。
- 演示资料：管理对外展示的 PDF、封面、版本和分享入口。
- 自动任务：北京时间 09:00 生成并推送每日重点，同时更新完整网站内容。
- 状态透明：区分内容日期、最后成功时间和失败状态。

## 架构原则

1. **模块注册制**：每个功能通过 `lib/module-registry.ts` 声明入口与能力，新增模块不会破坏现有内容。
2. **统一内容模型**：日报、演示稿、知识条目都使用统一元数据，便于搜索、标签、权限和归档。
3. **采集与发布分离**：失败的采集不会覆盖最后一次成功内容。
4. **仓库是可迁移的数据源**：结构化内容和公开资料保留在 Git 中，网站只是其中一种呈现方式。
5. **私密与公开分层**：公开日报和 PDF 可发布；个人笔记、密钥和未公开资料不进入公开目录。

## 目录

```text
app/                    网站界面与页面
components/             可复用界面组件
content/daily/           每日结构化内容
lib/content-model.ts     统一领域模型
lib/module-registry.ts   功能模块注册表
public/presentations/    可公开预览的 PDF
```

## 本地运行

```bash
pnpm install
pnpm dev
```

项目仍在第一阶段：界面骨架、扩展模型、GitHub 仓库和网站发布已经建立，真实采集与个人身份层将按模块逐步接入。
